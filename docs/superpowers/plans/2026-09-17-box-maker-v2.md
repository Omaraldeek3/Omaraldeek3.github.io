# Box maker v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the closed-box generator into a multi-type box maker with dividers, extras and a 3D preview.

**Architecture:** A 3D slab model (one axis-aligned cuboid per part + pairwise joint rules) is rasterised per part onto an exact breakpoint grid, traced into rectilinear loops, then post-processed (kerf, dogbones, rounding, round holes, labels). A client-only three.js viewer extrudes the same 2D shapes back onto their slabs.

**Tech Stack:** Next.js 16 client components, TypeScript 6, Playwright tests (node + browser), three.js 0.186.0.

**Spec:** `docs/superpowers/specs/2026-09-17-box-maker-v2-design.md`

## Global Constraints

- All geometry in millimetres; outline contours closed; engrave contours open with `layer: 'engrave'`.
- `three` and `@types/three` pinned to exactly `0.186.0`; imported only via dynamic `import('three')` inside `box3d.tsx`.
- Every user-facing string has English and Arabic via `tx(lang, en, ar)`.
- Existing toolkit tests stay green; run `npx tsc --noEmit`, `npx eslint src/toolkit tests`, and `npx playwright test tests/toolkit-*.spec.ts` before each task is done.
- No git repository: "commit" steps are replaced by running the full toolkit suite.

- Produces:
  - `type Axis = 0|1|2` ; `type Slab = { min:[number,number,number]; max:[number,number,number]; normal:Axis; u:Axis; v:Axis; flipV:boolean }`
  - `type Joint = { a:string; b:string; rule:'fingers'|'halflap'|'tenon'|{owner:string} }`

  - `type ModelPart = { name:string; slab:Slab; priority:number; label:string }`

  - `partOutline(model, name): { outer: Point[]; holes: Point[][] }` (untransformed, drawing coordinates)
  - `type BoxOptions = { type:'closed'|'open'|'liftoff'|'sliding'|'drawer'; width; depth; height; sizing:'inside'|'outside'; thickness; finger; kerf; clearance; spacing; rows; columns; labels:boolean; handHoles:{enabled:boolean;width:number;height:number;fromTop:number}; pull:'none'|'thumb'|'slot'; pullSize:number; cornerRadius:number; dogbone:number }`
  - `defaultBoxOptions: BoxOptions`
  - `buildBox(o): { parts: BoxPart[]; drawing: Drawing; outside; inside; counts:{width;depth;height}; skippedLabels:number }` with `type BoxPart = { name:string; shape:Shape; slab:Slab }`

```ts
function assertExclusive(o: BoxOptions) {
  const { model } = buildModelForTest(o); // exported from box/types as buildModel
  const t = o.thickness;
  for (const part of model.parts) {
    const xs = breakpoints(model, part); // exported test helper from panels.ts
    for (const [u0,u1] of pairs(xs.u)) for (const [v0,v1] of pairs(xs.v)) {
      const p = toWorld(part.slab, (u0+u1)/2, (v0+v1)/2, 0.5); // mid thickness
      const inside = model.parts.filter(q => contains(q.slab, p));
      if (!inside.length) continue;
      const owner = ownerAt(model, p);
      expect(inside.some(q => q.name === owner)).toBe(true);
    }
  }
}
```
Plus: every part's traced shape contains `ownerAt === part.name` cell centres and not others (sampled with point-in-polygon on the shape).
