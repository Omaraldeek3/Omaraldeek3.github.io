# عمر الديك — Omar Aldeek

## Cut Studio — أدوات التصميم والليزر

تتوفر سبع أدوات محلية في المتصفح على المسار `/tools`: ترتيب القطع، تحويل الصور إلى فيكتور، تنظيف المسارات، المقاس والتكرار، حساب تكلفة الخامة، اختبار التعشيق وتجهيز صور الحفر. الواجهة بالعربية والإنجليزية، مع استيراد SVG وDXF وCDR وتصدير SVG وDXF للعمل مع CorelDRAW وIllustrator وRDWorks. راجع [دليل الأدوات وحدودها](docs/TOOLKIT.md).

بورتفوليو شخصي كامل بالعربية والإنجليزية: هوية فحمية وعاجية، معرض أعمال بثلاثة نماذج أصلية، صفحات تفاصيل ومعاينات محلية، خدمات، طريقة عمل، نبذة، خيارات تعاون، أسئلة شائعة وتواصل.

## النسخة المنشورة

الموقع منشور على GitHub Pages: [omaraldeek3.github.io](https://omaraldeek3.github.io/) والأدوات على [/tools](https://omaraldeek3.github.io/tools/). كل دفع إلى الفرع `main` يعيد البناء والنشر تلقائياً عبر `.github/workflows/pages.yml`.

النسخة المنشورة ثابتة (بدون خادم)، لذلك استيراد CDR متاح فقط عند تشغيل Cut Studio على جهازك. على الموقع المنشور صدّر من CorelDRAW بصيغة SVG أو DXF. جميع الأدوات الأخرى تعمل داخل المتصفح.

للتجربة محلياً بنفس إعدادات النشر: احذف مؤقتاً `src/app/api` ثم شغّل البناء مع `GITHUB_PAGES=true`؛ الناتج في المجلد `out/`.

## التشغيل

استخدم Node.js 24 LTS (تم التطوير على 24.19.0). الحد الأدنى للإطار 20.9.

```sh
npm ci
npm run dev
```

افتح [العربية](http://localhost:3000/ar) أو [English](http://localhost:3000/en). الجذر `/` يحوّل إلى العربية. تبديل اللغة يحافظ على صفحة المشروع الحالية.

```sh
npm run typecheck
npm run lint
npm run build
npm start
```

البناء يولّد الصفحات مسبقًا مع App Router. لا توجد قاعدة بيانات أو حسابات أو خدمة إرسال أو اشتراكات. الخطوط والصور محلية بعد التثبيت؛ لا تُحمّل من Google Fonts أو Unsplash أثناء زيارة الموقع.

### وسائل التواصل المطلوبة

في `profile` داخل `src/content/site.ts`:

- `whatsapp`: رقم حقيقي دولي **بأرقام فقط** دون `+` أو مسافات. يترك فارغًا حتى توفره.
- `email`: بريدك الحقيقي. يترك فارغًا حتى توفره.
- `siteUrl`: أصل النطاق الفعلي عند النشر، مثل `https://your-domain.com` دون شرطة أخيرة. يفعّل canonical وروابط hreflang.

لا يوجد رقم أو بريد مختلق. لا تظهر روابط واتساب أو البريد حتى تتوفر قيم صالحة. زر التواصل يقود إلى قسم التواصل، الذي يشرح حالة البيانات غير المكتملة. خيار تجهيز موجز المشروع يحفظ ملفًا نصيًا على جهاز الزائر **ولا يرسله**. يبقى إدخال الموجز معطّلًا قبل تشغيل JavaScript، لمنع إرسال أصلي غير مقصود من المتصفح. لا توجد رسائل إرسال وهمية أو طلبات API لإرسال الموجز.

عند إضافة خدمة إرسال لاحقًا، يجب تنفيذ endpoint حقيقي والتحقق من المدخلات ومعالجة الخطأ والإرسال الناجح. الموقع الحالي لا يحتاجها.

### الأعمال والأسعار

النماذج `finjan` و`forma` و`madar` تصورات تصميمية وليست مشاريع عملاء. لكل منها صفحة تفاصيل ومعاينة محلية كاملة باللغتين. لا تُعرض نتائج تجارية أو شهادات أو شعارات عملاء. صور التصميم الداخلي صور مرجعية، وليست أعمالًا معمارية لعمر.

لإضافة مشروع: أضف سجلًا إلى `projects` بكلتا اللغتين، مع slug فريد وبيانات الهدف والحل والأجزاء المنفذة. يولّد `generateStaticParams` المسارات تلقائيًا. إضافة هوية جديدة تتطلب توسيع `SitePreview` وألوانها ومحتواها.

`copy.ar.options` و`copy.en.options` يحتويان `price: null`. أضف أسعارًا حقيقية اختياريًا إلى اللغتين؛ لا تظهر الأسعار افتراضيًا. الدومين والاستضافة ليسا مشمولين تلقائيًا.

## التفاعل وإمكانية الوصول

- Motion for React هو مكتبة الحركة الوحيدة. تمرير طبيعي دون اعتراض للعجلة أو اللمس.
- ميلان الافتتاحية يعمل فقط مع مؤشر دقيق وhover. الحركة محدودة، ودخول الكلمات لا يفصل الحروف العربية.
- بطاقات الأعمال تتراكم عند اتساع وارتفاع الشاشة الكافيين؛ الهاتف وتقليل الحركة يستخدمان تدفقًا رأسيًا طبيعيًا بلا مسافات مصطنعة.
- مؤشر مراحل العمل مرتبط بالسكرول. `prefers-reduced-motion` يوقف التتبع والـparallax والـstacking والحركات الكبيرة.
- قائمة موبايل native `dialog` مع حصر التركيز وEscape وإعادته. أسئلة شائعة عبر `details/summary` تعمل باللمس ولوحة المفاتيح.
- HTML حقيقي `lang` و`dir` لكل لغة، وخط عربي متصل دون letter-spacing، مع رابط تجاوز التنقل وتركيز مرئي.
- المحتوى الأساسي مكوّنات خادم؛ تقتصر مكوّنات العميل على الحركة والتنقل وموجز المشروع.

## اختبارات المتصفح

أُنجزت جولة تصميم إضافية ثم جولة مستقلة للموبايل والأداء. راجع [المراجعة البصرية وقياسات قبل/بعد](docs/DESIGN-REVIEW.md)؛ الفحص الأحدث يتضمن **19 اختبارًا ناجحًا**.

الاختبارات تستخدم Playwright وMicrosoft Edge المثبت محليًا. يعيد الاختبار استخدام الخادم الجاري، أو يشغّل خادم تطوير تلقائيًا إذا لم يكن موجودًا:

```sh
npm test
```

يمكن اختبار خادم محلي آخر عبر متغير البيئة `PORTFOLIO_TEST_URL`، مثل `http://localhost:3002`. تستخدم اختبارات المتصفح والروابط الداخلية هذا العنوان بدل العنوان الافتراضي.

إذا لم يكن Edge مثبتًا: غيّر `channel: "msedge"` في `playwright.config.ts` إلى متصفح مثبت، أو احذف `channel` ثم شغّل `npx playwright install chromium`.

التغطية تشمل اللغتين عند 360 و390 و768 و1024 و1440، عدم وجود overflow أفقي، أخطاء JavaScript، صفحات المشاريع والمعاينات، تبديل اللغة، لوحة المفاتيح واللمس، تقليل الحركة، التنزيل المحلي، وسلوك المحتوى دون JavaScript. النتائج الفعلية والحدود في [docs/QA.md](docs/QA.md).

## التوثيق والإصدارات

تم استدعاء Context7 فعليًا (`resolve-library-id` ثم `query-docs`) للمكتبات الأساسية. تم التحقق من الإصدارات المنشورة عبر سجل npm، ومراجعة التوثيق الرسمي وملفات التوثيق الخاصة بإصدار Next المثبت. التفاصيل وسبب اختيار الإصدارات المتوافقة في [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md).

المشروع جاهز للتشغيل والبناء محليًا. لم يُنشر إلى خدمة استضافة ولم يُربط بنطاق. يلزم رقم واتساب والبريد والنطاق الحقيقي لإكمال بيانات التواصل والنشر.
