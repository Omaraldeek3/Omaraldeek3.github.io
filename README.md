# عمر الديك — Omar Aldeek

بورتفوليو شخصي ثنائي اللغة. الموقع يقدّم عمر أولاً — مبرمج، مصمّم، باني أنظمة أتمتة — ويعرض أعماله الحقيقية في قسم واحد اسمه **المختبر**.

## المختبر

| العمل | الحالة | ما هو |
|---|---|---|
| مصنع الشورتس | يعمل | خط إنتاج حقيقي يدير قناتي شورتس عربية وإنجليزية: جدولة بـ n8n، كتابة بنموذج لغوي مع بديل احتياطي، مدقّق يرفض ويعيد، تعليق صوتي، مونتاج على VPS، ثم نشر |
| Cut Studio | يعمل | ثماني أدوات ليزر وتصميم تعمل داخل المتصفح. تطبيق مستقل على `/tools` |
| دراسات التصميم | يعمل | ثلاث دراسات باتجاه بصري كامل ومعاينات محلية. دراسات لا مشاريع عملاء |
| لوحة SaaS | قيد البناء | مسجّلة بحالة `building`، تظهر في المختبر بصدق وصفحتها تعطي 404 |

## التشغيل

Node.js 24 LTS. الحد الأدنى للإطار 20.9.

```sh
npm ci
npm run dev
```

الجذر `/` يحوّل إلى [العربية](http://localhost:3000/ar)؛ [English](http://localhost:3000/en) عبر مبدّل اللغة. التحويل يتم في `src/proxy.ts` — لاحظ أن `middleware.ts` صار اسمه `proxy.ts` في Next.js 16، وأنه يجب أن يكون بجانب `app`، أي داخل `src`.

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

## البنية

| المسار | الدور |
|---|---|
| `src/content/locales.ts` | اللغات، والعربية افتراضية بلا شرط |
| `src/content/site.ts` | كل نصوص اللغتين وبيانات الملف الشخصي والدراسات |
| `src/lab/registry.ts` | سجل أعمال المختبر — نقطة التمديد الوحيدة |
| `src/lab/<slug>/view.tsx` | عرض كل عمل |
| `src/ui/` | مكوّنات العرض |
| `src/lib/` | منطق خالص: المشهد، تحديد المعدل، التحقق، عنوان العميل |
| `src/toolkit/` | Cut Studio. يُغلَّف ولا يُعدَّل |
| `src/app/tools/` | قشرة Cut Studio المستقلة وورقة أنماطها |

### إضافة عمل جديد إلى المختبر

1. أضف مدخلاً في `src/lab/registry.ts` بحالة `building`.
2. أنشئ `src/lab/<slug>/view.tsx`.
3. اربطه في `src/app/[locale]/lab/[slug]/page.tsx` واقلب الحالة إلى `live`.

لا شيء آخر في الموقع يحتاج تعديلاً. الأعمال بحالة `building` تُعرض في المختبر مكتوباً عليها ذلك، وصفحاتها تعطي 404 بدل صفحة فارغة.

## النشر

الموقع يُنشر على Vercel. لا تصدير ثابت ولا `output: export`، لأن نموذج التواصل يحتاج مساراً على الخادم.

اضبط متغيرات `.env.example` في إعدادات المشروع للإنتاج والمعاينة:

- `NEXT_PUBLIC_SITE_URL` — نطاق الإنتاج بلا شرطة أخيرة. بدونه تُحذف `canonical` و `hreflang` بدل اختلاق نطاق.
- `CONTACT_TO_EMAIL` و `CONTACT_FROM_EMAIL` و `CONTACT_API_KEY` — وجهة نموذج التواصل.

خدمة الإرسال لم تُوصَل بعد. حتى ذلك الحين يعيد `/api/contact` رمز **503** صراحة وتعرض الواجهة «غير مفعّل». لا رسالة نجاح قبل إرسال فعلي. وصل الخدمة تغيير من موضع واحد في `src/app/api/contact/route.ts`.

اختبر مقابل النشر:

```sh
PORTFOLIO_TEST_URL=https://your-domain npx playwright test tests/routing.spec.ts tests/page.spec.ts tests/lab.spec.ts tests/seo.spec.ts
```

## حدود معروفة

- **استيراد CDR محلي فقط.** المسار `/api/tools/cdr` يقبل طلبات loopback وحدها بحكم تصميمه، ويحتاج ملفاً تنفيذياً على الجهاز (`CDR_CONVERTER_PATH`). على الموقع المنشور صدّر من CorelDRAW بصيغة SVG أو DXF. بقية الأدوات تعمل داخل المتصفح.
- **اختبارات CDR الثلاثة تُخفق بلا المحوّل المثبَّت.** هذا سلوك بيئة لا خلل في الكود.
- **تحديد المعدل في الذاكرة.** الحد لكل نسخة تشغيل لا عالمي. كافٍ لنموذج تواصل، وغير كافٍ لحماية شيء ثمين.

## قواعد التصميم

- العربية أولاً، والاتجاه يُبنى بخصائص CSS المنطقية لا `left` / `right`.
- اللون يعني حالة لا زينة: ما ليس حياً يبقى رمادياً.
- `prefers-reduced-motion` يوقف حلقة الرسم تماماً ويترك إطارة ساكنة مقروءة.
- الموقع يُقرأ كاملاً بلا JavaScript.
- لا بيانات وهمية عند أي فشل. الفشل يُعلن.
- وسيلة تواصل بلا قيمة صالحة تُخفى، ولا يُختلق لها بديل.

هذه القواعد مغطّاة باختبارات في `tests/`، وأهمها `a11y.spec.ts` و `theme.spec.ts` و `contact.spec.ts`.
